# PhonePe-Pulse-Data-Visualization-Exploration

## Project Overview

This project analyzes and visualizes PhonePe Pulse transaction data across India to uncover transaction trends, user growth patterns, and regional insights.
The interactive Power BI dashboard helps users explore financial transaction data using KPIs, filters, maps, and visualizations.

## Key Features

- Interactive Power BI Dashboard
- KPI Cards for key transaction metrics
- State-wise and district-wise analysis
- Geo-visual map analysis
- Transaction trend analysis
- User and insurance data exploration
- 10+ interactive filters and visualizations

## Project Insights

- Analyzed large-scale PhonePe transaction data across India
- Identified high-growth states and regions
- Compared transaction patterns across different states and districts
- Explored trends in digital payments and user adoption
- Created data-driven insights for regional market assessment

## Technologies Used

- Power BI
- Python
- SQL
- Pandas
- Excel

## Dataset

The dataset used in this project is based on PhonePe Pulse data and includes information related to:

- Aggregated Transactions
- Aggregated Users
- Map Transactions
- Map Users
- Top Transactions
- Top Users

## Dashboard

The dashboard includes:

1. Transaction Analysis
2. User Analysis
3. State-wise Performance
4. District-wise Performance
5. Year-wise Growth Trends
6. Interactive Maps and Filters

## Objective

The objective of this project is to transform raw fintech data into meaningful business insights and visualize digital payment trends across India.
